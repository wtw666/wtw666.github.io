# Tongwen Wu — Personal Academic Website

This repository contains the source for [wtw666.github.io](https://wtw666.github.io/).

The homepage presents one connected research identity: data and uncertainty, rigorous algorithms, and better business decisions. It is a dependency-free static site built with semantic HTML, responsive CSS, and a small navigation script.

## Updating the site

- Edit homepage content in `index.html`.
- Edit visual styles in `styles.css`.
- Replace `assets/portrait.jpg` to update the portrait.
- Update the Google Drive CV link in `index.html` when the file changes.

GitHub Pages publishes changes from the repository automatically.
